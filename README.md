# stop

полноэкранный монитор своей машины в терминале.

cpu по ядрам, gpu, память, zram, диски, сеть, температуры, процессы и кулеры. датчики ищутся по имени hwmon, индексы не зашиты. в sysfs отсюда ничего не пишется.

## запуск

```
python3 stop
```

нужны `psutil` и `blessed`, и настоящий терминал. окно хотя бы 80 на 28.

## клавиши

```
q            выход
?            справка
стрелки      процессы
c m n        сорт по cpu, памяти, имени
/            поиск
k            завершить выбранный
f            выбрать кулер
влево вправо шаг скорости 5%
0            вернуть авто
```

клик по строке выбирает процесс. клик по колонке cpu, ram или имя меняет сорт, повтор переворачивает. клик по полосе кулера ставит мощность от 1 до 100, кнопка авто возвращает плате.

кулеры крутит внешняя команда `fan`: `fan cpu 60`, `fan case 60`, `fan gpu 60`, `fan auto`. без неё панель только показывает обороты.
